# NEXUS // AI Trading Terminal

## Project Overview
Autonomous AI trading terminal with a Bloomberg-inspired dark UI. React/TanStack Start frontend with a Python FastAPI backend for position management, price data, and LLM-driven trade ideas.

## Architecture
- **Frontend**: TanStack Start (React 19) + Tailwind CSS v4 + Vite
- **Backend**: Python FastAPI server in `server/` (runs on port 8000)
- **Database**: SQLite via `server/db.py`
- **Pricing**: `yfinance` via `server/prices.py`
- **AI/LLM**: Configurable providers (Ollama, OpenAI, etc.) via `server/llm.py`
- **Charts**: `lightweight-charts` for candlestick charts, custom SVG for equity/daily P&L

## Key Files
| File | Purpose |
|------|---------|
| `src/routes/index.tsx` | Main dashboard (all views, modals, charts, primitives) |
| `src/routes/__root.tsx` | Root layout, error/404 components, QueryClient provider |
| `src/styles.css` | Bloomberg theme: CSS vars, custom utilities (`terminal-panel`, `pulse-dot`, `glow-amber`) |
| `vite.config.ts` | Vite config with `/api` proxy to `localhost:8000` |
| `server/main.py` | FastAPI app, CORS, all API routes and Pydantic models |
| `server/agent.py` | AI trading agent loop (cycle-based) |
| `server/llm.py` | LLM provider abstraction |
| `server/prices.py` | Market price fetching via yfinance |
| `server/db.py` | SQLite schema and queries |
| `server/context.py` | Agent context builder for LLM prompts |

## Development
```bash
# Frontend
npm install
npm run dev              # starts on :3000

# Backend (separate terminal)
cd server
python -m venv .venv && source .venv/bin/activate  # or .venv\Scripts\activate on Windows
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

The frontend proxies `/api/*` to `http://localhost:8000` via Vite dev server.

## Conventions
- **Styling**: Tailwind CSS v4 with `@theme inline` vars. Use semantic color tokens (`bull`, `bear`, `primary`, `muted-foreground`), not raw colors.
- **Fonts**: JetBrains Mono (mono/body), Space Grotesk (display/headings). Applied via `@fontsource/*`.
- **UI pattern**: `terminal-panel` utility class for card containers. All text uppercase with wide tracking for labels.
- **API calls**: Frontend uses `fetchJson<T>()` helper in `index.tsx`. No React Query on the main page (manual polling via `setInterval`).
- **Asset classes**: `forex | stock | crypto | cfd | futures` -- defined as a union type and ordered by `ASSET_CLASS_ORDER`.

## Important Notes
- SSR is disabled on the index route (`ssr: false`) because the dashboard depends on browser APIs and the backend.
- The `vite.config.ts` uses a shared TanStack config package that bundles many plugins. Do NOT manually add `tanstackStart`, `viteReact`, `tailwindcss`, `tsConfigPaths`, or `nitro` -- they are already included.
- `routeTree.gen.ts` is auto-generated by TanStack Router. Do not edit manually.
- The project has Supabase integration scaffolding (`src/integrations/supabase/`) but auth is currently unused.
